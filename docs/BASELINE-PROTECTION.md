# حماية الـBaseline — لعبة «مين طفى المدينة؟»

هذا الملف يثبت حدود التطوير المعتمدة قبل مرحلة تحسين الـUI/UX.

## النسخة المرجعية

- مرجع المحتوى والمنطق: `e32f35b`.
- الحارس الآلي: `src/test/game-logic-lock.test.ts`.
- بصمات المرجع: `src/test/fixtures/game-logic-baseline.json`.

## محمي تمامًا: لا تعديل بدون موافقة صريحة

| النطاق | المصدر | ما الذي يحميه |
| --- | --- | --- |
| الأدلة والأرقام وبيانات المهمات | `public/game/index.html` بين `building the data` و`state` | نصوص الأدلة، القيم، المعدلات، الأسئلة، الإجابات، أشجار التفكيك، والدروس المرتبطة بالحالات. |
| منطق التحليل | `why`, `plant`, `flatDim`, `refreshFlat`, `recalc`, `assemble`, `level1`–`level4`, `startLevel`, `openTile`, `answerWhy`, `fixLeaf` | إنشاء المهمة، التفكيك، الوصول للأسباب، وتصحيحها. |
| الفوز والخسارة والنقاط | `starsFor`, `lose`, `win`, وClick router | شروط الفوز والخسارة، الانتقال المنطقي، النجوم، والنقاط. |
| القواعد الرقمية | `PENALTY` وقيم `opt`, `budget`, `time` ومعادلات النجوم والنقاط | الوقت، عدد التفكيكات، العقوبات، والنتيجة. |

## قابل للتطوير مع بقاء الحماية فعالة

| التصنيف | أمثلة مسموح تطويرها |
| --- | --- |
| واجهة | التخطيط، الـHUD، الألوان، التباين، الأزرار، المسافات، حالات الـfocus، التنقل البصري. |
| سيناريو | حوار البداية، رئيس المدينة، المفكرة، النصوص الإرشادية خارج الأدلة، عناوين الواجهة. |
| حركة وصوت | ظهور العناصر، ردود الفعل، الأنيميشن، ترتيب الـVoice-over، المزج الصوتي. |
| نتائج | شكل بطاقات الفوز والخسارة، ترتيب عرض النجوم والمجموع، ما دام حسابها ومنطقها ثابتين. |

## قاعدة العمل

أي تغيير في واجهة اللعبة يجب أن يمر مع بقاء اختبار `game-logic-lock` ناجحًا. إذا فشل الاختبار، لا يُقبل التغيير إلا بعد مراجعة صريحة تؤكد أن التعديل المقصود يقع خارج المحمي.

## ملاحظة عن النصوص

نص الدليل نفسه محمي بالحرف، بما في ذلك الأرقام والصياغة. يمكن فقط تعديل النصوص المحيطة به: عنوان الشاشة، تعليمات اللعب، الرسائل الإرشادية، والحوار القصصي.
